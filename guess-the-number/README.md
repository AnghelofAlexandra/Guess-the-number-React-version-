# Guess the Number

A simple interactive number guessing game built with React and Vite.

The player has to guess a randomly generated number between 1 and 100. After each guess, the application provides feedback to help the player find the correct number.

## Features

- Random number generation between 1 and 100.
- User input for submitting guesses.
- Feedback indicating whether the guess is too high or too low.
- Attempts counter.
- Input validation.
- Maximum of 10 attempts.
- Game-over state when the player wins or runs out of attempts.
- Restart functionality to start a new game.

## Technologies

- React
- JavaScript
- CSS
- Vite

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd guess-the-number
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
